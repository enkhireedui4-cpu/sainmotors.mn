## Review Focus

- Slow/rejected lead submission: preserve input, show failure, prevent duplicate submission; test real handler/transport against controlled HTTP.
- Whitespace names, invalid phones, and missing consent: reject before persistence; literal test cases.
- Keyboard and short mobile viewport: trap modal focus, Escape returns focus, no overflow; browser tests.
- Switching hero/terrain/features: update the actual image/details without losing the request form; browser tests in both locales.
- Remote service unavailable/unconfigured: never show fake success; label deployment status separately and keep local contact reachable.
