# CHERY RELY R8 хуудасны шинэчлэл

## Зорилго

Одоо байгаа `/mn/brands/rely/`, `/en/brands/rely/` хуудсыг
https://cherycvglobal.com/R8 эх загварын зураг, бүтэц, ажиллагаанд тулгуурлан
R8-ийн бүрэн танилцуулга болон туршилтын жолоодлогын хүсэлт авах хуудсаар хөгжүүлнэ.
Хэрэглэгч одоогийн CHERY RELY хуудсын screenshot-оор өөрчлөх байршлыг тодруулсан.

## Approaches

1. **Одоогийн Next.js төсөлд R8-д зориулсан тусдаа component нэмэх — санал болгож буй арга.**
   Одоо байгаа хаяг, Sain Motors header/footer, брэндийн мэдээлэл болон MN/EN
   дэмжлэгийг ашиглана. Эхийн харагдац, ажиллагааг React/CSS-ээр дахин хэрэгжүүлнэ.
2. **Үйлдвэрлэгчийн хуудсыг iframe-аар оруулах.** Өөр серверийн lead хүлээн авагч,
   навигаци, cookie banner, хэлний агуулга дагалдах тул хэрэглэгчийн хүссэн
   Sain Motors дотоод хуудасны шийдэлд тохирохгүй.
3. **Үйлдвэрлэгчийн Nuxt bundle-ийг шууд ажиллуулах.** Чужийн analytics, global
   style, API хамаарал, засварлахад хүндрэлтэй runtime дагалдана. Сонгохгүй.

Хэрэглэгч CHERY RELY дотоод хуудсанд хэрэгжүүлэх заавраа тодруулж, Supabase
төслийг сонгон login/init/link хийж дууссанаа мэдэгдсэн. Энэ зааврын дагуу
эхний аргаар хөгжүүлэлтийг үргэлжлүүлж байна.

## Хуудсын бүтэц

Одоогийн CHERY RELY гарчиг, breadcrumb, үндсэн холбоо барих үйлдлүүдийн дараа:

1. Эхийн хоёр том banner зураг; desktop/mobile-д зориулсан тусдаа зураг,
   өмнөх/дараах товч, сонгогдсон banner-ийн тэмдэглэгээ.
2. RELY брэндийн зорилго, гурван үнэт зүйл. Одоо байгаа RELY болон Sain Motors-ийн
   албан ёсны борлуулагчийн мэдээллийг тохирох хэсэгт нэгтгэнэ.
3. Далайн эрэг / уул / зам / ой гэсэн дөрвөн сонголттой зурагт танилцуулга.
4. TOUGH / STRONG / RELIABLE / INTELLIGENT гэсэн дөрвөн дэлгэрэх хэсэг.
   Desktop-д зурагтай зэрэгцээ мэдээлэл; mobile-д хаах товчтой бүтэн дэлгэцийн
   мэдээлэл. Эхийн зураг, техникийн агуулга, дарааллыг ашиглана.
5. Үйлдвэрийн нэмэлт тоноглолын хэсэг.
6. Үйлдвэрлэгчийн гурван хөдөлгүүр/хурдны хайрцгийн хувилбарын танилцуулга.
   CONFIGURATION үйлдэл нь локал dialog-д эхийн бүрэн үзүүлэлтийн зургийг нээнэ;
   зургийг томоор нээх/татах холбоос, keyboard хаах үйлдэлтэй байна. Эх сайт
   `/R8detail` рүү шилжиж `R8detailmb.jpg` зургийг үзүүлдэг нь нэмж батлагдсан.
7. Эхийн lead хэсэгтэй адил: зүүнд шар R8-ийн хажуугийн зураг, баруунд форм;
   mobile-д зураг болон формыг доош дараалуулна.
8. Монгол дахь одоогийн Sain Motors showroom, RELY-ийн 7222-8855 утас,
   газрын зураг болон бусад брэндийн холбоос.

Үйлдвэрлэгчийн эх хуудас нь export загварын мэдээлэл. Баталгаажаагүй Монгол
хувилбарын тоноглол, үнэ, нийлүүлэлтийг зохиож нэмэхгүй. MN/EN бичвэрийг тусад нь
хадгалж, одоогийн Sain Motors-ийн бодит мэдээлэлтэй нийцүүлнэ.
Импортолсон үзүүлэлт/хувилбарын ойролцоо MN/EN тайлбар байрлуулж, Монголд
нийлүүлэх хувилбарын тоноглолыг RELY борлуулалтын багаас тодруулахыг заана.
Хуучин ерөнхий hero/overview/model хэсгийг шинэ R8 хэсгүүд орлоно; давхар бүтэн
`BrandDetail` харуулахгүй. Showroom болон бусад брэндийн хэсгийг хадгална.

## Lead форм

- Улс, нэр, овог, утас, хувийн мэдээлэл ашиглах зөвшөөрөл.
- Монгол хувилбарт Монгол Улсыг анхны сонголт болгоно; эхийн улс сонголтын
  өгөгдлийг локал эх сурвалж болгон хадгална.
- Хоосон/зөвхөн зайтай утга, буруу утас, зөвшөөрөөгүй илгээлтийг ойлгомжтой алдаагаар зогсооно.
- Илгээж байх үед дахин илгээхээс хамгаална; алдаа гарвал бөглөсөн мэдээллийг хадгална.
- Хүлээн авагч API амжилт баталгаажуулсны дараа л амжилттай гэсэн төлөв харуулна.
- Үйлдвэрлэгчийн API руу хэрэглэгчийн lead илгээхгүй. Эх хуудсын SOUEAST гэж
  буруу нэрлэсэн privacy текстийг хуулж ашиглахгүй; Sain Motors-ийн privacy
  мэдээллийг шинээр орж буй lead үйлдэлтэй нийцүүлэн шинэчилнэ.
- **Хэрэглэгчийн сонголт:** `uzffaelpmhwffcuiqgjq` Supabase төслийг холбох
  `login`, `init`, `link` командыг өгсөн. Lead хүлээн авагчийг энэ Supabase
  төсөл дээр бэлтгэнэ. CLI 3.1.0 татаж checksum шалгасан; `init` амжилттай.
  Хэрэглэгч login/link-ийг Windows орчноос дуусгасан; локал link cache-д яг энэ
  project ref батлагдсан. Agent орчин CLI-ийн нэвтрэх эрхийг уншихгүй байгаа
  тул remote deploy/хадгалалт баталгаажаагүй. Тэр хүртэл production
  хадгалалт/хүргэлт бэлэн гэж үзэхгүй.
  Frontend болон transport-ийн шалгалтыг тусгаарласан тестийн хүлээн авагчтай
  баталгаажуулж болно.
- Static export учраас Next API route/server action-аар POST хүлээж авахгүй.
  Сонгосон үйлчилгээнээс хамаарч гаднын endpoint эсвэл hosting дээрх handler
  ашиглана. Хүлээн авагчгүй үед production илгээлтийг идэвхжүүлэхгүй; шууд
  RELY багтай холбогдох боломж байна. Нууц түлхүүр browser кодод орохгүй.

## Техник ба харагдац

- Одоо байгаа Next.js 16.4 / React 19 / static export бүтцийг ашиглана.
- Бусад брэндийн нийтлэг component-ийг эвдэхгүй, R8-ийн style-ийг тусгаарлана.
- Үйлдвэрлэгчийн JS-ийг production дээр ажиллуулахгүй; carousel, tab, dialog,
  формыг React-ээр шинээр хэрэгжүүлнэ. Нэмэлт dependency шаардахгүй.
- Зургийн эх харьцаа, тунгалаг дэвсгэрийг хадгалж, шаардлагатай хэмжээнд
  WebP хувилбар бэлтгэнэ; source original-уудыг татсан нотолгоонд хадгална.
- MN үсэг дэмждэг одоогийн фонтыг ашиглан эхийн хэмжээ, зай, өнгөнд тааруулна.
- Keyboard, харагдах focus, dialog focus/escape, reduced motion дэмжинэ.
